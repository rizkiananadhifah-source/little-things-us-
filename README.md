# little things, us ♡
Website diary pasangan dengan tampilan pink soft cute, mini phone UI, modal interaktif, musik dari file lokal, wish list, dan pesan kenangan.
Coba di perangkat sendiri
Buka index.html di browser. Fitur musik menggunakan file audio yang kamu pilih dari perangkat.
Publikasikan gratis dengan GitHub Pages
Masuk ke https://github.com/ dan buat akun/login.
Buat repository baru, misalnya little-things-us, dan pilih Public.
Upload index.html dari folder ini ke root repository.
Buka Settings → Pages.
Pada bagian Build and deployment, pilih Deploy from a branch.
Pilih branch main dan folder /(root), lalu Save.
Tunggu proses publikasi, lalu buka URL yang ditampilkan di halaman Pages.
Panduan resmi: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
Personalisasi
Ubah judul dan teks di index.html.
Ganti placeholder kenangan dengan foto milikmu (bisa pakai tag <img> dan file gambar yang di-upload ke repository).
File musik tidak disertakan. Pilih audio dari perangkat saat membuka situs, atau ubah kode agar memakai file audio yang memang boleh kamu bagikan.
Website ini statis: catatan diary dan wish list demo tidak disimpan ke database dan tidak otomatis tersinkron antarperangkat.
Privasi
GitHub Pages yang dipublikasikan dapat dilihat siapa pun. Jangan unggah alamat rumah, nomor telepon, kata sandi, atau informasi pribadi yang sensitif. Gunakan foto dan musik yang kamu punya izin untuk membagikannya.
